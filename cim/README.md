# CIM – Certified Innovation Manager (RUB-Akademie)

Tools, die aus den Kursinhalten der CIM-Fortbildung entstanden sind.

## Tools

| Tool | Modul / Tag | Thema | Beschreibung |
|---|---|---|---|
| [Stage-Gate-Assistent](tools/stage-gate-assistent/) | Modul 1, Tag 3 | Innovationsprozesse (Cooper) | Fragt Projektdaten, Deliverables, Must-/Should-meet-Kriterien und die Gate-Entscheidung ab und erzeugt ein Gate-Protokoll als Markdown. Alte Protokolle lassen sich laden und zum nächsten Gate fortführen. |
| [Bröring-Arbeitsblätter](tools/broering-arbeitsblaetter/) | Bröring: BM-Design für Technologiesysteme | TPM, Value Proposition Canvas, Ecosystem Pie Model | Drei Arbeitsblätter mit Erklärungen ausfüllen, im Layout der Originalvorlagen als PNG/SVG ausgeben, als .md/.json speichern und laden. |
| [Agile-Stage-Gate-Planer](tools/agile-stage-gate-planer/) | Modul 1, Tag 3 | Agile-Stage-Gate-Hybrid (Cooper) | Projekt aufsetzen und Sprint für Sprint führen: Stages, Hypothesen, Sprint-Reviews, Gates, grafische Auswertung und Projektdokument als Markdown. |

## Neues Tool hinzufügen

1. `_vorlage-tool/` nach `tools/<tool-name>/` kopieren.
2. `README.md` ausfüllen, Tool als `index.html` (oder Skript) ablegen.
3. Zeile in der Tabelle oben ergänzen.
